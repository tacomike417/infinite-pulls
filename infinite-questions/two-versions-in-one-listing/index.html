Two Versions in One Listing

@KitchenTableTrainer asks

I have several versions of a card. Can I use one listing and send whichever one is handy?

Jeff answers

Only if the listing and platform setup clearly let the buyer choose or understand exactly what they'll receive. I'd normally keep distinct versions identifiable. Our app can help compare their references, but similarity isn't interchangeability. The buyer should get the version they knowingly purchased.

— Jeff, infinitepulls.com
