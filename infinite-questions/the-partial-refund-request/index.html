The Partial Refund Request

@NervousNinetales asks

buyer wants a partial refund for wear I already showed. Do I just pay to end the conversation?

Jeff answers

I'd compare the complaint with the listing and photos, then use the platform's resolution process. You can be open to a fair solution without automatically accepting any requested amount. If your description was wrong, own that. If it was accurate, present the evidence calmly and let the process work.
