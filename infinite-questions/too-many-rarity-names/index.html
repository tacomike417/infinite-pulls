Too Many Rarity Names

@Squintle asks

IR, SIR, full art, secret rare... every time I learn a word somebody adds three more. Do I need to memorize all this?

Jeff answers

No, and I wouldn't try to learn every era at once. Start with the official rarity names for the set you're collecting, then learn the shorthand people use around it. Some casual terms describe appearance and don't line up perfectly with official categories. When I'm unsure, I match the card number and set first. You can identify a card before you know all the vocabulary.

— Jeff, infinitepulls.com
