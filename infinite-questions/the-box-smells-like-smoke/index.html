The Box Smells Like Smoke

@TooManyWeedles asks

collection came from a smoker's house. Can I spray something in the box to fix the smell?

Jeff answers

I wouldn't spray cards or add scented treatments around them. I'd separate the collection from the old packaging, use clean appropriate storage, and get advice before attempting anything else. Be honest about any remaining odor when selling. Covering up a smell isn't the same as resolving it.

— Jeff, infinitepulls.com
