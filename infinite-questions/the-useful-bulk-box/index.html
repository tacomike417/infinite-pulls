The Useful Bulk Box

@CornerConcerned asks

how do I separate useful deck-building cards from the rest of my extras if I barely know the game?

Jeff answers

I'd ask an experienced player or local organizer to help identify current needs, then label a dedicated section for those cards. @TooManyWeedles started with sheer volume; sorting by purpose makes it manageable. Don't assume every plain-looking card is equally unwanted, or that last year's useful pile stays unchanged forever.

— Jeff, infinitepulls.com
