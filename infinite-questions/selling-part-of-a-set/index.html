Selling Part of a Set

@ClosetCleanoutCrew asks

I need to thin things out but hate the idea of breaking up a set I worked on. How do you pick what goes?

Jeff answers

I'd start with why you're thinning the collection: space, money, or changing interests. Then compare keeping the set intact with selling selected cards, using our app to understand the approximate values involved. Set aside anything you'd strongly regret losing before taking offers. You don't have to make every decision in one sitting, and finishing a set once doesn't obligate you to keep it forever.

— Jeff, infinitepulls.com
