How Is Card 215 in a Set of 198?

@SlabConfused asks

this card says 215/198. I was never great at math but that seems illegal 😂

Jeff answers

You're reading it correctly. Some sets include cards numbered beyond the main set total; collectors often call these secret-numbered cards or secret rares, depending on the era. The numbering system leaves room for those extras. I use the exact set checklist to see what belongs where. The number tells us which card we're looking at, but it doesn't tell us its price by itself.

— Jeff, infinitepulls.com
