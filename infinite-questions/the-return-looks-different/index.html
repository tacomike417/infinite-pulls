The Return Looks Different

@BuyersRemorsechu asks

a returned card doesn't look like the one I sent. How would you handle that?

Jeff answers

I'd compare it with my original photos and records, document the differences, and report the specific concern through the platform's return process. Avoid accusations before checking. Keep the packaging too. Good records are most useful when they let you describe an observable mismatch clearly.

— Jeff, infinitepulls.com
