Mixed Conditions in One Set

@HoloAndBroke asks

half my set is really clean and half is played. Does that ruin it as a collection?

Jeff answers

Not for enjoying it. I'd record each card honestly and decide whether consistent condition is actually one of your goals. If you later sell, describe the mixture clearly rather than giving the whole set its best card's label. Upgrading can happen gradually if you decide it matters.

— Jeff, infinitepulls.com
