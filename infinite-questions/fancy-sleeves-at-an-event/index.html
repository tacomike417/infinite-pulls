Fancy Sleeves at an Event

@NervousNinetales asks

can I use any cool sleeves I want when playing, or are there rules about that too?

Jeff answers

I'd check the event's current rules and ask the organizer if you're unsure. Sleeve condition and consistency can matter in organized play. Bring an appropriate spare set if needed. Choosing sleeves you enjoy is fine; verifying they're suitable before the event avoids a rushed change at the table.

— Jeff, infinitepulls.com
