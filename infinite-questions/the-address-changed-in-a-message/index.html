The Address Changed in a Message

@BinderMath asks

buyer wants me to ship somewhere different from the order. Is that a simple edit?

Jeff answers

I'd follow the platform's approved process for address changes rather than improvising from a message. Shipping to an unapproved address can complicate protection and delivery records. Ask the platform how to correct the order before sending it. A little administrative patience can prevent a much bigger mix-up.

— Jeff, infinitepulls.com
