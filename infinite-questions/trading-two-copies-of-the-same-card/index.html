Trading Two Copies of the Same Card

@TwoLanguageTrainer asks

we both have the same card but want to swap because we prefer each other's centering. Is that ridiculous?

Jeff answers

Not if both people understand the differences and want the exchange. Inspect each copy completely; centering isn't the only condition detail. You can value appearance differently without either person being wrong. I'd just make sure enthusiasm about one feature doesn't hide something else that matters.

— Jeff, infinitepulls.com
